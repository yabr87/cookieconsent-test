CookieConsent Demo

Test page for the free CookieConsent plugin

This example is prepared for quick integration into Webflow: the theme lives in a separate CSS file, the config lives in a separate JS file, and the banner automatically follows <html lang>.

Tip: the banner uses autoDetect: "document" and updates automatically when <html lang> changes.

What this demo checks

Consent modal rendering, preferences modal layout, button states, readonly necessary cookies, and the analytics toggle.

File structure

Everything related to the banner is grouped inside the cookieconsent-banner folder with separate CSS and JS files.

Reset flow

The reset button clears consent and reloads the page so the banner appears again in a clean state.
